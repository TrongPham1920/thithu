# Mock Exam Design References

This file records the ideas behind the skill. Use it when improving the skill itself or when a UI task needs a stronger design-quality frame.

## Taste Skill Pattern

Purpose:

- Prevent generic AI-generated frontend output.
- Encourage better decisions around hierarchy, typography, spacing, motion, and visual direction.
- Push output toward complete, usable product screens instead of demos.

Ideas to borrow:

- Decide the design direction before coding.
- Avoid boilerplate-looking UI.
- Check the result against product intent, not only against compile success.

## Claude Frontend Skills Pattern

Purpose:

- Make AI frontend work less generic and more intentional.
- Encourage memorable, well-structured UI.

Ideas to borrow:

- Avoid default card grids, weak typography, and random gradients.
- Create hierarchy through layout, contrast, density, and copy structure.
- Make the primary action obvious.

## Anthropic Frontend Design Pattern

Purpose:

- Force frontend agents to think visually before implementation.

Ideas to borrow:

- Define visual direction first.
- Choose typography, spacing, layout, and motion deliberately.
- Review design quality before finishing.

## Project Skill Pattern

Purpose:

- Keep product-specific design rules close to the app.
- Let the quiz workflow override generic frontend taste rules.

Ideas to borrow:

- Keep rules short and enforceable.
- Keep the current learning state visible in the UI.
- Update `.codex/skills/mock-exam-app/SKILL.md` as the product direction becomes clearer.

## Awesome Rules Pattern

Purpose:

- Use markdown rules that AI coding agents can follow quickly.

Ideas to borrow:

- Separate general rules from project-specific rules.
- Prefer concrete do/don't instructions.
- Keep the active skill lean and move background material here.
